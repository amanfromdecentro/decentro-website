##  Overview

The open-source project in question appears to be a web application, with its codebase primarily residing under the website" directory. The core functionalities are centered around optimizing user experience and enhancing analytics insights by implementing real-time data interaction features through Firebase Auth and Measurement tools.The project's purpose revolves around improving web interactions for end-users by utilizing modern JavaScript libraries and utility scripts. For instance, it includes a module (sgInputValidators.js) that validates input data across different formats focusing on phone numbers, emails, and OTPs (One Time Passwords), making the registration and authentication processes more secure.The use of axios for API calls, both optimized and custom instances in axios.js and axios-sg.js, respectively, ensures efficient interaction within the applications architecture. Additionally, a well-structured next.config.js file manages redirect behavior for specific product categories within the app, streamlining user navigation and providing a smoother experience. Lastly, sgUrls.js handles a collection of URLs, likely used for API requests or navigation purposes, adding to the overall functionality of this intriguing open-source project.
